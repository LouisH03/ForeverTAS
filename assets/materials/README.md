# ForeverTAS replacement textures

These textures are original, procedurally generated ForeverTAS assets. They do
not contain pixels extracted from TrackMania or any other game.

Run `tools/generate_replacement_textures.sh` with ImageMagick 7 to reproduce
every committed PNG. The fixed integer patterns, colors, strengths, dimensions,
and graphic overlays in that script are the complete source.

The images are released under the same license as ForeverTAS. TrackMania
material identifiers are used only at runtime to select one of these
project-owned material families.
